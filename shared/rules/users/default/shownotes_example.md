## 📖 名词解释

- **卢德运动（Luddite Movement）**：19世纪初英国工人以砸毁纺织机、蒸汽机的方式抗议工业革命，后引申为"抵抗新技术的人"
- **Meritocracy Fellowship**：Palantir推出的面向高中生的奖学金项目，招SAT达到藤校分数线的学生，跳过大学直接进入真实项目
- **蒸馏（在本期语境）**：把某人（同事/自己）的工作经验、决策方式训练进AI/Agent，让AI能代替其完成任务
- **反蒸馏**：为了避免被AI替代而反向操作——故意让蒸馏效果差，显得"AI还是不如我"
- **游侠 / 一人公司（OPC）**：带着AI工具箱为企业或个人提供服务的个体从业者，相对于大厂（领主）、AI原生中小公司（城邦）、传统行业（旧贵族）
- **人的异化（马克思）**：机器作为生产资料出现后，人生产的东西不再属于自己，反而变成机器的附属品
- **Orchestrator（编排者）**：在AI时代，人的核心价值之一是编排、调度多个AI协同工作
- **具身智能（Embodied AI）**：让AI拥有物理身体（如人形机器人），能进入物理世界执行任务
- **Vibe Coding**：用自然语言描述意图，让AI生成代码的编程方式——不需要精通语法，也能造东西
- **Hackathon（黑客马拉松）**：短时间（通常24-48小时）组队用技术解决一个具体问题的活动
