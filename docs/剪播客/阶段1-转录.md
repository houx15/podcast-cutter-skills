# 阶段1：转录

## 概述

将原始录音转换为带词级时间戳的文字数据（words.json）。

## 子阶段

### 1.0 prepare_audio.py

将输入音频转换为工作格式：单声道、16-bit PCM WAV，保留原始采样率。

- 输入：任意格式音频（.m4a/.wav/.mp3）
- 输出：`input/working_track1.wav`（双轨时增加 `working_track2.wav`）、`input/audio_meta.json`
- 模式：`single_track`（1个输入）或 `two_track`（2个输入）

### 1.2 volcano_submit.py + volcano_query.py

提交音频到 Volcano Engine v3 AUC 大模型 ASR，轮询直至完成。

- 端点：`https://openspeech.bytedance.com/api/v3/auc/bigmodel/`
- 认证：新控制台用 `X-Api-Key`；旧控制台用 `X-Api-App-Key` + `X-Api-Access-Key`
- 资源：`volc.seedasr.auc`（中文，词级时间戳，支持说话人分离）
- 任务ID保存至 `1_transcribe/task_id_track{N}.txt`
- 原始结果保存至 `1_transcribe/volcano_raw_track{N}.json`

### 1.3 transcribe_merge.py

解析 Volcano 原始 JSON，合并多轨词流，输出 `words.json`。

- 双轨：两条词流按 `start_ms` 排序合并，S1/S2 对应 track1/track2
- 单轨：说话人来自 Volcano `enable_speaker_info` 输出
- `words.json` 是所有下游阶段的权威数据源

### 1.4 make_sentences.py

将词序列按说话人切换、停顿（≥500ms）或长度（≥50字符）分割为句子。

- 输出 `sentences.json`，每句引用 words.json 中的词索引范围

## 常见错误码

| 代码 | 含义 | 处理方式 |
|------|------|----------|
| 20000000 | 成功 | — |
| 20000001 | 处理中 | 继续轮询 |
| 45000001 | 参数无效 | 检查 API key 和音频格式 |
| 45000002 | 音频为空 | 用 ffprobe 检查源文件 |
| 45000132 | 超 512 MB | 转码压缩后重试 |
| 55000031 | 服务繁忙 | 等待后重试 |
