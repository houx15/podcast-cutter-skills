# 阶段3：审查

## 概述

人工复核 AI 的剪辑建议，确认或修改删除区间，导出最终决策。

## 操作流程

1. **生成审查页面**
   ```bash
   python shared/scripts/generate_review_html.py --ep-dir output/<ep>
   ```
   生成 `3_review/review_enhanced.html` 和初始 `3_review/review_state.json`。

2. **启动本地服务**
   ```bash
   python shared/scripts/review_server.py --ep-dir output/<ep> --port 5050
   ```

3. **在浏览器中审查**
   打开 `3_review/review_enhanced.html`，审查每条删除建议。
   服务通过 `PATCH /state` 实时保存用户操作到 `review_state.json`。

4. **导出最终决策**
   在页面中点击"导出"或调用：
   ```bash
   curl -X POST http://localhost:5050/export \
     -H 'Content-Type: application/json' \
     -d '{"user_notes": "...", "feedback_for_learning": []}'
   ```
   生成 `3_review/delete_segments_edited.json`。

## delete_segments_edited.json Schema

```json
{
  "deletes": [
    {
      "start_ms": 12300,
      "end_ms": 28100,
      "level": "rough",
      "reason": "录前闲聊",
      "source": "ai_rough",
      "user_action": "kept"
    }
  ],
  "user_notes": "前3分钟全删",
  "feedback_for_learning": []
}
```

`user_action` 取值：`kept`（保留AI建议）、`edited`（用户修改后保留）、`rejected_by_user`（取消删除）、`added`（用户新增）。
