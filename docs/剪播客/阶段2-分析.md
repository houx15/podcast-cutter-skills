# 阶段2：分析

## 概述

三轮 LLM 分析，逐步识别应删除的片段，最终输出机器审查建议供人工复核。

## 子阶段

### 2.1 analyze_rough.py — 粗剪

按段落级别识别大段删除区域：录前闲聊、完全题外话、长停顿等。

- 规则来源：`shared/rules/editing/*.md`（按文件名排序，拼接后作为 system prompt）
- 输出：`2_analysis/rough_cuts.json`，`level="rough"`, `source="ai_rough"`

### 2.2 analyze_fine.py — 精剪

在粗剪基础上，识别词级别填充词和冗余内容。

- 额外上下文：`words.json`（前200词）+ `rough_cuts.json`（跳过已标记区间）
- 输出：`2_analysis/fine_cuts.json`，`level="fine"`, `source="ai_fine"`

### 2.3 self_review.py — 自审

LLM 对 rough+fine 建议进行质检：找出误删（false positive）和漏删（false negative）。

- 输出：`2_analysis/self_review.json`，包含 `deletes`（补充建议）、`flags`（误删标记）、`summary`

## 删除记录 Schema

```json
{
  "start_ms": 12300,
  "end_ms": 28100,
  "level": "rough",
  "reason": "录前闲聊",
  "source": "ai_rough",
  "confidence": 0.83,
  "evidence_word_idx": [42, 138]
}
```

## 自定义规则

- 编辑规则：`shared/rules/editing/*.md`
- 用户偏好：`shared/rules/users/<userId>/preferences.yaml`
- 热词：`shared/rules/users/<userId>/hotwords.txt`（输入给 Volcano corpus.context.hotwords）
