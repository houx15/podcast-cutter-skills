# 快速上手：从录音到 cut.wav

本文以一期双轨访谈录音为例，完整走完阶段 1–4。

---

## 前提

```bash
pip install -e ".[dev]"
ffmpeg -version          # 需要 5.x 或更高
grep -E 'VOLC_API_KEY' .env
```

`.env` 中至少需要填写：

```dotenv
VOLC_API_KEY=your_volcano_key
VOLC_RESOURCE_ID=volc.seedasr.auc
```

---

## 标准流程

### 阶段 1：转录

#### 1.0 准备音频

```bash
python shared/scripts/prepare_audio.py \
  --ep-dir output/2026-05-08-ep01 \
  --track1 recordings/host.m4a \
  --track2 recordings/guest.m4a
```

输出：`output/2026-05-08-ep01/input/working_track*.wav`、`audio_meta.json`

#### 1.05 双轨对齐（可选）

若两轨录音开始时间不同，选择以下一种对齐方式：

```bash
# 录音前有拍掌声（ASR 之前运行）
python shared/scripts/align_tracks.py --ep-dir output/2026-05-08-ep01 --clap

# 知道各轨录制开始时间（ASR 之前运行）
python shared/scripts/align_tracks.py --ep-dir output/2026-05-08-ep01 --t1 10:00:00 --t2 10:00:03

# 从文字内容推断（默认，ASR 完成后、合并之前运行）
python shared/scripts/align_tracks.py --ep-dir output/2026-05-08-ep01
```

#### 1.2 Volcano ASR

```bash
# Track 1
python shared/scripts/volcano_submit.py \
  --audio-file output/2026-05-08-ep01/input/working_track1.wav \
  --track-num 1 --ep-dir output/2026-05-08-ep01
python shared/scripts/volcano_query.py --track-num 1 --ep-dir output/2026-05-08-ep01

# Track 2
python shared/scripts/volcano_submit.py \
  --audio-file output/2026-05-08-ep01/input/working_track2.wav \
  --track-num 2 --ep-dir output/2026-05-08-ep01
python shared/scripts/volcano_query.py --track-num 2 --ep-dir output/2026-05-08-ep01
```

约需 5–30 分钟，视音频时长而定。

#### 1.3 合并词流 + 1.4 分句

如使用文字推断对齐，先运行 `align_tracks.py`（无参数），再运行以下两步：

```bash
python shared/scripts/transcribe_merge.py --ep-dir output/2026-05-08-ep01
python shared/scripts/make_sentences.py --ep-dir output/2026-05-08-ep01
```

输出：`1_transcribe/words.json`、`1_transcribe/sentences.json`

---

### 阶段 2：AI 分析（agent 执行）

不运行脚本。读取以下文件：

- `output/2026-05-08-ep01/1_transcribe/sentences.json`
- `shared/rules/editing/*.md`
- `shared/rules/users/default/preferences.yaml`

依次写入三个 JSON 文件：

1. `output/2026-05-08-ep01/2_analysis/rough_cuts.json` — 粗剪（内容级，录前闲聊、题外话、技术故障）
2. `output/2026-05-08-ep01/2_analysis/fine_cuts.json` — 精剪（词/句级，口头禅、冗余重复）
3. `output/2026-05-08-ep01/2_analysis/self_review.json` — 自审（误删标记 + 遗漏补充）

详细格式见 `.claude/skills/podcast-cut-剪播客/SKILL.md` 的"阶段 2"节。

---

### 阶段 3：人工审查

```bash
# 生成审查 HTML
python shared/scripts/generate_review_html.py --ep-dir output/2026-05-08-ep01

# 启动本地审查服务器
python shared/scripts/review_server.py --ep-dir output/2026-05-08-ep01 --port 5050
```

在浏览器中打开打印出的 HTML 路径，审查删除建议：

- **保留**：接受建议
- **编辑**：调整时间区间后保留
- **拒绝**：取消这条删除
- **新增**：手动标记需要删除的区间

审查完成后点击"导出"，自动生成 `3_review/delete_segments_edited.json`。

---

### 阶段 4：剪辑

```bash
python shared/scripts/cut_audio.py --ep-dir output/2026-05-08-ep01
python shared/scripts/trim_silences.py --ep-dir output/2026-05-08-ep01
```

输出：`output/2026-05-08-ep01/4_cut/cut.wav`

---

## 续传与幂等性

每个脚本输出唯一文件，已完成的阶段跳过（由 agent 判断）。

若需重跑某个阶段，删除对应输出文件夹后重跑对应脚本：

```bash
# 重跑分析（保留转录结果）
rm -rf output/2026-05-08-ep01/2_analysis output/2026-05-08-ep01/3_review output/2026-05-08-ep01/4_cut

# 重跑切割（保留所有分析）
rm -rf output/2026-05-08-ep01/4_cut
```

## 自定义剪辑规则

- **编辑规则**：修改 `shared/rules/editing/*.md`，下次运行分析阶段时生效
- **用户偏好**：`shared/rules/users/default/preferences.yaml`（积极程度、置信度阈值）
- **热词**：`shared/rules/users/default/hotwords.txt`（提高 ASR 对专有名词的识别率，需在提交 ASR 前修改）

## 常见错误

| 错误 | 原因 | 处理 |
|------|------|------|
| `45000001` | Volcano API key 无效 | 检查 `.env` 中的 `VOLC_API_KEY` |
| `45000132` | 音频超过 512 MB | `ffmpeg -i input.m4a -ar 16000 -ac 1 -b:a 48k output.mp3` |
| uguu.se 上传失败 | 文件过大或网络问题 | 配置 `TOS_*` 或 `S3_*`，见 [docs/configuration.md](../configuration.md) |
| `silence trap` | ffmpeg 输出静音 | 检查输入音频是否有效 |
