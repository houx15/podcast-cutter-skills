# 快速上手：从录音到 cut.wav

本文以一期双轨访谈录音为例，完整走完阶段 1–4。

---

## 前提

```bash
pip install -e ".[dev]"
ffmpeg -version          # 需要 5.x 或更高
grep -E 'VOLC_API_KEY|LLM_API_KEY' .env
```

`.env` 中至少需要填写：

```dotenv
VOLC_API_KEY=your_volcano_key
LLM_API_KEY=your_ark_key
LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_MODEL=doubao-seed-2-0-code-preview-260215
```

---

## 标准流程（推荐）

### 第一步：运行流水线

```bash
python shared/scripts/run_pipeline.py \
  --ep-dir output/2026-05-08-ep01 \
  --track1 recordings/host.m4a \
  --track2 recordings/guest.m4a
```

流水线自动完成转录 + 分析，约需 5–30 分钟，结束时打印：
- 审查文件路径
- 启动本地审查服务器的命令
- 完成后续步骤的命令

**双轨对齐选项（可选）**

若两轨录音开始时间不同，在运行流水线前或同时指定对齐方式：

```bash
# 录音前有拍掌声
python shared/scripts/run_pipeline.py ... --align clap

# 知道各轨录制开始时间（如录制软件显示的时间戳）
python shared/scripts/run_pipeline.py ... --align timestamp --t1 10:00:00 --t2 10:00:03

# 不指定时，ASR 完成后自动从文字内容推断（默认）
python shared/scripts/run_pipeline.py ...
```

### 第二步：人工审查

流水线在阶段 3.0 结束后暂停，打印审查文件路径。启动本地服务器：

```bash
python shared/scripts/review_server.py --ep-dir output/2026-05-08-ep01 --port 5050
```

在浏览器中打开流水线打印出的 HTML 路径，审查 AI 的删除建议：
- **保留**：接受 AI 建议
- **编辑**：调整时间区间后保留
- **拒绝**：取消这条删除
- **新增**：手动标记需要删除的区间

审查完成后点击"导出"，自动生成 `3_review/delete_segments_edited.json`。

### 第三步：完成剪辑

```bash
python shared/scripts/run_pipeline.py --ep-dir output/2026-05-08-ep01 --resume
```

输出：`output/2026-05-08-ep01/4_cut/cut.wav`

---

## 续传与幂等性

每个阶段检测输出文件是否已存在，已完成的阶段自动跳过。在任意阶段中断后直接重新运行同样的两条命令即可续传，无需手动记录进度。

若需重跑某个阶段（例如修改了剪辑规则），删除对应输出文件夹后重新运行流水线：

```bash
rm -rf output/2026-05-08-ep01/2_analysis
python shared/scripts/run_pipeline.py --ep-dir output/2026-05-08-ep01
```

## 自定义剪辑规则

- **编辑规则**：修改 `shared/rules/editing/*.md`，下次运行分析阶段时生效
- **用户偏好**：`shared/rules/users/default/preferences.yaml`（积极程度、置信度阈值）
- **热词**：`shared/rules/users/default/hotwords.txt`（提高 ASR 对专有名词的识别率，需在提交 ASR 前修改）

## 常见错误

| 错误 | 原因 | 处理 |
|------|------|------|
| `45000001` | Volcano API key 无效 | 检查 `.env` 中的 `VOLC_API_KEY` |
| `45000132` | 音频超过 512 MB | `ffmpeg -i input.m4a -ar 16000 -ac 1 -b:a 48k output.mp3` |
| uguu.se 上传失败 | 文件过大或网络问题 | 配置 `TOS_*` 或 `S3_*`，见 [docs/configuration.md](../configuration.md) |
| `silence trap` | ffmpeg 输出静音 | 检查输入音频是否有效 |
| `delete_segments_edited.json not found` | 审查未完成 | 在浏览器中点击导出后再 `--resume` |
