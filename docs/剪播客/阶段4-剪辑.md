# 阶段4：剪辑

## 概述

依据 `delete_segments_edited.json` 精确剪切音频，输出 `cut.wav`。

## cut_audio.py

**逻辑：** KEEP 区间 = `[0, duration_ms]` 减去所有已激活的删除区间（取反）。

- 仅处理 `user_action != "rejected_by_user"` 的删除条目
- 重叠删除区间先合并再取反
- 每个拼接点使用 25ms 三角形交叉淡化（`acrossfade=d=0.025:c1=tri:c2=tri`）
- 输出前通过 `ffmpeg volumedetect` 验证峰值 > -10 dB（防止"静音陷阱"）

```bash
python shared/scripts/cut_audio.py --ep-dir output/<ep> [--track-num 1]
```

## trim_silences.py

裁剪 cut.wav 首尾静音，保留最多 200ms 静音过渡。

- 使用 `ffmpeg silencedetect=n=-50dB:d=0.1s` 检测静音边界
- 若首尾无显著静音则跳过（幂等）
- 原地覆盖 cut.wav（临时文件 → 原子替换）

```bash
python shared/scripts/trim_silences.py --ep-dir output/<ep>
```

## 关于"静音陷阱"

podcastcut 反馈记录（2026-02-02）：ffmpeg 可成功退出但输出静音文件（-91 dB）。
所有音频写操作都通过 `lib/ffmpeg_wrap.run_ffmpeg` 路由，内置 volumedetect 检查。

## 输出

- `4_cut/cut.wav`：PCM 16-bit，单声道，与输入相同采样率
- `4_cut/logs/`：ffmpeg 操作日志（调试用）
